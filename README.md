# A História Certa

Página de vendas do workshop A História Certa, conduzido por Silvania, autora e fundadora do Amo Livros.

## Cliente

Silvania, Amo Livros.

## Tecnologias

React, TypeScript, Vite e CSS responsivo.

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três páginas de vendas compartilham a mesma estrutura e alteram somente a comunicação da hero.

## Execução local

```bash
pnpm install
pnpm dev
```

## Build de produção

```bash
pnpm build
```

O resultado é gerado na pasta `dist`.

## Checkout

Defina `VITE_CHECKOUT_URL` no ambiente da Vercel quando o endereço oficial estiver disponível. Sem essa variável, os botões direcionam até a oferta e informam que o checkout ainda está em preparação.
